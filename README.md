# UBOT Broadcast Studio V8
Frontend-first, no bridge dependency. The dashboard is a polished local preview workspace with responsive scrolling, dark/light mode, group selection, draft tools and preview-only broadcast flow.

## Deploy
Deploy the project root to Vercel. No Telegram bridge is required for the UI.

## Telegram
A real Telegram client/session must live in a separate backend you control. This frontend deliberately does not collect OTP or 2FA credentials.
